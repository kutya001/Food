# Запрос № 001: Разработка правил проекта и настройка структуры истории

**Дата и время:** 2026-08-18 10:05

## Текст запроса пользователя
> Напиши для себя правло по написанию проекта. 
> Нужно использовать такие технологи, чтоб оно запускалось на github pages. 
> 
> Создай папку .artifacts и внутри три папки Запрос, Пална, Выполнено. В этих папках всегда нужно создавать md файлы которые буду служить для меня историей. Пропиши это вправилах, эти файлы нужно именовать так "Номер - название короткое - дата и время" всегда в таком порядке.

## Ключевые требования:
1. **Стек под GitHub Pages:** Приложение должно быть полностью статическим, работать в браузере без серверного бэкенда (HTML5, Vanilla CSS / CSS Tokens, Modular JS / ES Modules, LocalStorage / IndexedDB).
2. **Папка `.artifacts/`:** Создать структуру папок:
   - `.artifacts/Запрос/`
   - `.artifacts/Планы/`
   - `.artifacts/Выполнено/`
3. **Регламент версионирования истории:** На каждую задачу/этап формировать историю в виде `.md` файлов.
4. **Формат именования:** `Номер - название короткое - дата и время.md` (например, `001 - Имя - 2026-08-18_10-05.md`).
5. **Фиксация в правилах:** Закрепить данные правила в системных конфигурациях проекта (`GEMINI.md`, `AGENTS.md`).
