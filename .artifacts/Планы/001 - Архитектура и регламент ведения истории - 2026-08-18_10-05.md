# План № 001: Архитектура приложения под GitHub Pages и внедрение системы артефактов

**Дата и время:** 2026-08-18 10:05

## 1. Архитектурная концепция под GitHub Pages
Поскольку GitHub Pages поддерживает исключительно статический хостинг (HTML, CSS, JS, JSON, медиафайлы), разработка платформы общепита базируется на следующих принципах:

1. **SPA (Single Page Application) без бэкенд-сервера:**
   - Модульная структура на чистом JavaScript (ES Modules).
   - Клиентский Hash-роутинг (`#/showcase`, `#/menu`, `#/cart`, `#/pos`, `#/warehouse`, `#/recipes`, `#/requests`, `#/admin`, `#/analytics`).
2. **Клиентская база данных и стейт-менеджмент:**
   - Хранилище `localStorage` / `IndexedDB` для имитации сервера и БД.
   - Предзагруженные демонстрационные данные (демо-блюда, техкарты, ингредиенты, организации, меню, заказы).
   - Модуль симуляции авторизации и переключения ролей (Клиент / Общепит / Организация-заказчик / Админ).
   - Функции экспорта и импорта базы данных в JSON для сохранения состояния пользователем.
3. **Дизайн-система и 5 тем:**
   - Файл `css/tokens.css` с полным набором CSS Custom Properties для тем `fresh`, `appetite`, `neo-dark`, `corporate`, `premium`.
   - Мгновенное переключение тем через атрибут `data-theme` на теге `<html>`.
   - Защита от FOUC через inline-инициализатор.

## 2. Организация папок и структуры проекта
```
Food/
├── .artifacts/
│   ├── Запрос/          # История входящих задач
│   ├── Планы/           # Планы архитектуры и этапов
│   └── Выполнено/       # Отчеты о выполнении
├── GEMINI.md            # Системные правила проекта для ИИ
├── AGENTS.md            # Системные правила проекта
├── index.html           # Главная точка входа SPA
├── css/
│   ├── tokens.css       # 5 тем и цветовые токены
│   ├── base.css         # Сброс стилей, типографика, база
│   └── components/      # Стили компонентов
├── js/
│   ├── app.js           # Главный контроллер и роутер
│   ├── state/           # Управление состоянием и LocalStorage
│   ├── theme/           # Модуль переключения тем
│   └── views/           # Экраны (Витрина, Бизнес, POS, Админ и т.д.)
└── data/
    └── mock_data.json   # Начальные данные для общепитов, блюд, складов
```
