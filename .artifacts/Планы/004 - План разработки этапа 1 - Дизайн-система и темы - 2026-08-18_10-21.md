## 3. Детальный состав работ

### Шаг 1.1: Спецификация CSS-токенов (`css/tokens.css`)
* Реализация семантических переменных для 5 тем:
  1. `fresh` (Свежий рынок) — `#22A05B` / `#FF8A3D` / `#F6F9F3`
  2. `appetite` (Тёплый аппетит) — `#E63946` / `#F8A24B` / `#FFF6EE`
  3. `neo-dark` (Нео-дарк) — `#C2F04C` / `#0F141A` / `#1B242E`
  4. `corporate` (Корпоративный баланс) — `#0F7B84` / `#F5A524` / `#F3F8F9`
  5. `premium` (Гастро-премиум) — `#6D2144` / `#D2A24C` / `#FBF6F0`
* Реализация статусных токенов (`--color-success`, `--color-warning`, `--color-error`, `--color-info` с адаптацией под светлый/тёмный режим).
* Внедрение 8-цветной палитры графиков (`--data-viz-1` ... `--data-viz-8`).
* Токены геометрии: радиусы скруглений (`--radius-sm`, `--radius-md`, `--radius-lg`, `--radius-full`), тени (`--shadow-sm`, `--shadow-md`, `--shadow-lg`).

### Шаг 1.2: Базовые стили и общие компоненты (`css/base.css`, `css/layout.css`)
* Подключение шрифта Google Font *Manrope* (веса 400, 500, 600, 700, 800).
* Плавный transition цвета (250 мс) с правилом `@media (prefers-reduced-motion: reduce) { * { transition: none !important; } }`.
* Стили базовых элементов: кнопки (primary, accent, secondary, ghost, icon-btn), бейджи, инпуты, карточки, сетка flex/grid.
* Стили разметки: Sticky Header, мобильное нижнее меню, модальные оверлеи, тосты.

### Шаг 1.3: Модуль `ThemeManager` (`js/theme/themeManager.js`)
* Конфигурационный справочник 5 тем с метаданными (названия, HEX-коды для превью, описания, рекомендованные роли).
* Метод `initTheme()`:
  * Проверка сохраненной темы в `localStorage`.
  * При отсутствии — назначение дефолта по роли или `fresh`.
  * Установка атрибута `data-theme` на тег `<html>`.
* Метод `setTheme(themeKey)`:
  * Мгновенная смена `data-theme`.
  * Сохранение в `localStorage` и публикация кастомного события `themeChanged`.
  * Обновление активного маркера в UI.
* Метод `openThemeModal()`:
  * Рендер модального окна с карточками-превью всех 5 тем.
  * Интерактивные мини-палитры с образцами primary, accent, surface.
  * Мгновенное переключение темы по клику с визуальной галочкой.

### Шаг 1.4: Интеграция точки входа (`index.html`, `js/app.js`)
* Внедрение критического inline-скрипта в `<head>`:
  ```javascript
  (function() {
    const saved = localStorage.getItem('food_app_theme') || 'fresh';
    document.documentElement.setAttribute('data-theme', saved);
  })();
  ```
* Подключение модулей через `<script type="module" src="js/app.js"></script>`.
* Рендер стартового экрана-демонстратора дизайн-системы и палитр (с возможностью протестировать все кнопки, инпуты, карточки и статусы в каждой из 5 тем).

## 4. Критерии приёмки Этапа 1

1. [ ] При загрузке страницы тема применяется мгновенно без мерцания (FOUC).
2. [ ] Кнопка-палитра в шапке открывает окно выбора из всех 5 тем.
3. [ ] Клик по любой теме мгновенно и плавно меняет весь интерфейс без перезагрузки страницы.
4. [ ] Выбранная тема сохраняется в `localStorage` и восстанавливается после обновления страницы.
5. [ ] Тексты во всех 5 темах легко читаются и соответствуют стандарту доступности WCAG 2.1 AA.
6. [ ] Все интерактивные элементы (кнопки, инпуты, карточки, статусы) используют исключительно CSS-токены.
