## 1. Архитектурная декомпозиция Этапа 3

Этап 3 превращает онлайн-витрину в полноценный фудтех-маркетплейс с интерактивной картой, детализацией нутриентов КБЖУ, корзиной и трекером заказов.

```
Food/
├── css/
│   ├── components/
│   │   ├── showcase.css             # Стили фильтров, сетки блюд, бейджей, карточек заведений
│   │   ├── modal.css                # Модальное окно блюда с КБЖУ прогресс-барами
│   │   ├── map.css                  # Стили интерактивной карты, маркеров и поп-апов
│   │   ├── drawer.css               # Выдвижная шторка корзины (Cart Drawer)
│   │   └── tracker.css              # Таймлайн статуса заказа
├── js/
│   ├── components/
│   │   ├── dishDetailModal.js       # Модалка блюда: КБЖУ, аллергены, состав, добавление
│   │   ├── mapComponent.js          # Интерактивная карта заведений и маршрутов
│   │   ├── cartDrawer.js            # Шторка корзины: расчет суммы и суммарного КБЖУ
│   │   ├── checkoutModal.js         # Оформление заказа (доставка/самовывоз, оплата)
│   │   └── orderTrackerModal.js     # Живой трекер статусов заказа
│   └── views/
│       └── showcaseView.js          # Каталог, поиск, мультифильтры, переключение Вид/Карта
```

## 2. Детальный состав работ

### Шаг 3.1: Стили компонентов витрины, карты и корзины
* Создание CSS-файлов компонентов на базе токенов без жестких цветов:
  * Адаптивная панель мультифильтров (поиск, категории, заведения, диапазон цен, калории, чекбоксы аллергенов и диет).
  * Карточки блюд с эффектами hover, бейджами КБЖУ и кнопкой быстрого заказа.
  * Интерактивная векторная карта (стили маркеров со статусом «Открыто/Закрыто», адаптация под светлые темы и тёмную тему `neo-dark`).
  * Стили выдвижной шторки корзины (`right: 0`, плавный slide-in) со сводкой КБЖУ заказа.
  * Стили модального окна оформления заказа и таймлайна доставки.

### Шаг 3.2: Модуль корзины (`js/components/cartDrawer.js`)
* Управление состоянием корзины (`items: [{menuItemId, qty, price, kbju}]`).
* Сохранение корзины в `localStorage` (синхронизация при перезагрузке).
* Подсчет итоговой суммы в сомах и суммарного баланса КБЖУ (калории, белки, жиры, углеводы) всей корзины.
* Обновление индикатора корзины в Header (`#cart-count`).

### Шаг 3.3: Модальное окно детализации блюда (`js/components/dishDetailModal.js`)
* Фотография/иконка блюда, название, заведение, категория, описание, вес порции.
* Интерактивная панель нутриентов (КБЖУ):
  * Калории (ккал), Белки (г), Жиры (г), Углеводы (г).
  * Цветные прогресс-бары (% от суточной нормы).
* Полный состав ингредиентов из связанной техкарты.
* Блок аллергенов с предупреждающими значками (Глютен, Лактоза, Орехи и т.д.).
* Селектор количества порций и поле особых пожеланий к заказу.
* Кнопка «Добавить в корзину» с анимацией добавления.

### Шаг 3.4: Интерактивная карта заведений (`js/components/mapComponent.js`)
* Интерактивная векторная карта Бишкека с нанесением точек:
  * Столовая «Свежесть» (ул. Токтогула, 125)
  * Бургерная «TaomGo» (пр. Чуй, 178)
  * Ресторан «GastroHall» (бул. Эркиндик, 45)
  * Корпоративные офисы: ОсОО «Alfa Tech», ОАО «Бишкек Финанс».
* Маркеры с бейджами статуса заведения (Открыто / Закрыто) и рейтингом.
* Всплывающие карточки по клику на заведение с переходом к просмотру меню.
* Адаптивная цветовая схема карты (тёмная для `neo-dark`, светлая для `fresh`, `appetite`, `corporate`, `premium`).

### Шаг 3.5: Модуль витрины и расширенной фильтрации (`js/views/showcaseView.js`)
* Живой поиск (по названию, категории, ингредиентам).
* Фильтры:
  * По категориям (Все, Супы, Вторые блюда, Салаты, Бургеры, Стейки).
  * По заведениям.
  * По диапазону цен в сомах (например, до 200 сом, 200–500 сом, 500+ сом).
  * По калорийности (легкие блюда до 300 ккал, сытные 300-600 ккал, плотные 600+ ккал).
  * По диетическим тегам (*Халяль*, *Веган*, *Без глютена*).
  * Исключение аллергенов (без глютена, без лактозы и т.д.).
* Переключатель режимов отображения: «🍽️ Каталог блюд» $\leftrightarrow$ «🗺️ Карта общепитов».

### Шаг 3.6: Оформление заказа и Трекер (`js/components/checkoutModal.js`, `js/components/orderTrackerModal.js`)
* Выбор типа: «Курьерская доставка» vs «Самовывоз».
* Ввод адреса доставки и контактов.
* Выбор способа оплаты: «Наличные», «Банковская карта», «Корпоративный счёт».
* Создание записи в коллекции `orders` базы данных `db.insert('orders', ...)`.
* Всплывающий трекер статуса заказа с анимацией таймлайна (`Принят` $\rightarrow$ `Готовится на кухне` $\rightarrow$ `Курьер в пути` $\rightarrow$ `Доставлен`).
