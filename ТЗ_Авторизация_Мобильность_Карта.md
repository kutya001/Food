# ТЕХНИЧЕСКОЕ ЗАДАНИЕ
## Разработка системы полноценной авторизации (RBAC), адаптивной мобильной версии и интерактивной карты FoodFlow

---

## 1. ОБЩИЕ СВЕДЕНИЯ И ЦЕЛИ ПРОЕКТА

### 1.1. Назначение системы
Платформа **FoodFlow** — единая экосистема для автоматизации общепита и организации питания сотрудников в Кыргызской Республике (все расчеты в национальной валюте — **кыргызский сом / KGS**). 

### 1.2. Цели настоящего Технического задания:
1. **Полноценная авторизация и изоляция ролей (RBAC):** исключить несанкционированный доступ, предоставить каждому пользователю строго персональный интерфейс, защитить маршруты (Route Guards) и реализовать безопасное хранение сессий.
2. **Полноценная мобильная версия (Mobile-First UX):** создать удобный адаптивный интерфейс для смартфонов и планшетов с нижней панелью навигации (Bottom Bar), шторками (Bottom Sheets), мобильными фильтрами и тач-управлением.
3. **Интерактивная карта (Full Interactive Map Engine):** разработать полнофункциональную карту Бишкека с панорамированием, масштабированием (Pinch-to-zoom / кнопки зума), геометками заведений и офисов, радиусами доставки и авто-определением локации пользователя.
4. **Совместимость с GitHub Pages:** 100% статическая архитектура (Vanilla HTML5 / CSS3 / ES Modules JS, Hash Routing).

### 2.2. Сценарии аутентификации:
1. **Вход по Логину и Паролю:** ввод `Email / Телефон` и `Пароль`.
2. **Быстрый вход по PIN-коду (для POS-кассира):** 4-значная сенсорная цифровая клавиатура (Numpad) для моментальной разблокировки кассы.
3. **Регистрация нового аккаунта:**
   * Выбор типа: *Частный покупатель (B2C)*, *Владелец заведения (B2B)* или *Юридическое лицо / Организация*.
   * Заполнение реквизитов (ИНН, название компании, контакты).
4. **Быстрое Демо-переключение (для тестирования):** переключение в 1 клик между преднастроенными профилями (Гость, Шеф столовой, Кассир, HR-директор, Суперадмин).
5. **Выход из системы (Logout):** очистка токена сессии с возвратом на экран логина.

### 2.4. Требования к Route Guards (Маршрутные Охранники):
* При переходе по прямому URL (например, `#/admin` гостем) срабатывает проверка `AuthManager.canAccess(route, userRole)`.
* При отказе в доступе:
  1. Выводится информационный Toast: `⚠️ Доступ запрещён для вашей роли`.
  2. Осуществляется автоматический редирект на домашний экран разрешенной роли (например, клиента на `#/showcase`, бизнеса на `#/business`).
* **Динамическая шапка:** пункты меню в Navigation Bar скрываются автоматически, отображая только доступные для текущего пользователя разделы.


### 3.1. Архитектурные элементы мобильного интерфейса:
1. **Нижняя панель навигации (Bottom Navigation Bar):**
   * Фиксированное положение внизу экрана (`position: fixed; bottom: 0`).
   * Крупные touch-target кнопки (высота не менее 56px, отступы под safe-area на iOS).
   * Иконки разделов в зависимости от роли (Меню, Карта, Заказы, Кабинет, Профиль).
2. **Мобильное гамбургер-меню (Offcanvas Drawer):**
   * Плавный выезд слева при нажатии на `[≡]`.
   * Содержит переключатель 5 тем (`fresh`, `appetite`, `neo-dark`, `corporate`, `premium`), профиль пользователя, смену роли и кнопку «Выход».
3. **Мобильная шторка фильтров (Bottom Sheet Filters):**
   * Выдвижная шторка снизу с выбором диапазонов цен в сомах, калорийности, аллергенов и диетических тегов.
4. **Трансформация таблиц в карточки (Responsive Card Flow):**
   * На экранах шириной менее 768px таблицы склада, техкарт и P&L автоматически превращаются в удобные мобильные карточки с аккордеонами деталей.
5. **Мобильная адаптация POS-терминала:**
   * Переключение между тач-плитками меню и чеком заказа через плавающую плашку внизу: `🧾 Чек: 3 поз. (620 сом) →`.

### 4.1. Функциональные требования к карте:
1. **Интерактивное управление полотном карты:**
   * Плавное перемещение (Pan & Drag мышью или пальцем).
   * Масштабирование (Zoom In / Zoom Out кнопками `+`/`−` и жестом Pinch-to-zoom).
   * Центрирование по координатам Бишкека (центр: Чуй / Эркиндик / Токтогула).
2. **Геометки объектов со статусами в реальном времени:**
   * Иконки заведений (`🍲` Столовые, `🍔` Бургерные, `🍷` Рестораны, `🏢` B2B офисы).
   * **Пульсирующие индикаторы:**
     * 🟢 Зелёный пульсирующий бейдж — *Открыто прямо сейчас*.
     * 🔴 Красный бейдж — *Закрыто*.
3. **Интерактивные всплывающие карточки (Map Popup / Bottom Sheet):**
   * При тапе/клике на маркер снизу всплывает информационная карточка: фото-иконка, рейтинг, адрес, средний чек в сомах, время доставки и прямая кнопка «🍽️ Открыть меню».
4. **Определение геолокации клиента (Geolocation API):**
   * Кнопка «📍 Где я» определяет координаты пользователя и отображает синюю пульсирующую точку на карте.
   * Расчет расстояния по формуле гаверсинусов (Haversine Formula) в километрах до каждого заведения.
   * Фильтр заведений: *«Поблизости (< 2 км)»*, *«В радиусе 5 км»*.
5. **Адаптация стиля карты под 5 тем платформы:**
   * При смене темы (`fresh`, `appetite`, `neo-dark`, `corporate`, `premium`) карта автоматически меняет цветовую гамму подложки, дорог и подписей улиц через CSS-фильтры и CSS Custom Properties.

## 6. КРИТЕРИИ ПРИЁМКИ

1. [ ] Пользователь может зарегистрироваться, войти по паролю, PIN-коду или переключить демо-профиль.
2. [ ] Каждая роль видит строго предназначенные ей страницы; при попытке несанкционированного перехода происходит блокировка с предупреждением.
3. [ ] На смартфонах (< 768px) доступен нижний Bottom Navigation Bar, гамбургер-меню и адаптивные карточки блюд/таблиц.
4. [ ] Интерактивная карта поддерживает зум, перетаскивание, геолокацию, расчет дистанции в км и переключение под все 5 тем.
5. [ ] Все расчеты, лимиты и чеки производятся исключительно в **кыргызских сомах (KGS)**.
6. [ ] Приложение запускается на **GitHub Pages** без серверных зависимостей и ошибок консоли.
